# Polarity Puzzle

Polarity Puzzle is a logic-based puzzle implemented across multiple programming languages to demonstrate language paradigms and problem-solving approaches. The goal is to solve the puzzle consistently across all versions.

## Languages
- Smalltalk (in progress)
- Rust (partial solution)
- Elixir (pending)
- Haskell (pending)

## Status
- Smalltalk: In progress
- Rust: Partial
- Elixir: Not started
- Haskell: Not started

## Folder Structure
- `/smalltalk` – Smalltalk implementation
- `/rust` – Rust implementation
- `/elixir` – Elixir implementation
- `/haskell` – Haskell implementation
- `/gui-tool` – GUI tool for analyzing and solving boards efficiently
